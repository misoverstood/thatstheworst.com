download youtube media (+ others) from terminal. a configuration guide for mac osx 10.7 (lion)

1. download and install Python [link: [http://python.org/download/]](http://python.org/download/%5D) (choose Python 2.7.3 Mac OS X 64-bit/32-bit x86-64/i386 Installer (for Mac OS X 10.6 and 10.7)
2. download youtube-dl [link: [http://rg3.github.com/youtube-dl/download.html]](http://rg3.github.com/youtube-dl/download.html%5D)
3. copy youtube-dl to /usr/local/bin/
4. make youtube-dl executable [sudo chmod +x /usr/local/bin/youtube-dl]
